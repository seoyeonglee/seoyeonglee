# Seoyoung Lee — Project Portfolio

I build practical projects around **security, privacy, audit analytics, risk detection, and automation**.

This GitHub is intentionally project-focused: each public repository is designed to be understandable on its own, reproducible, and safe to share without employer data or proprietary logic.

## Featured project

### [Privacy Access Monitor](https://github.com/seoyeonglee/privacy-access-monitor)

An explainable Python pipeline that detects unusual access to sensitive customer data using behavioral baselines, rule-based controls, and risk scoring.

**Python · Pandas · Privacy Monitoring · Anomaly Detection · Risk Scoring**

Key ideas:
- off-hours and weekend access
- geographic mismatch
- large exports
- unusual-system access
- multi-customer access bursts
- transparent 0–100 risk scoring
- synthetic data and reproducible tests

- **Explainable:** clear assumptions, limitations, and decision logic
- **Practical:** built around concrete monitoring, investigation, or control problems
